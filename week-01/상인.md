# useActionState

`useActionState`는 form action 의 결과에 따라 상태를 관리할 수 있게 해주는 Hook

`useActionState`의 전신인 `useFormState`는 form 제출에 특화된 hook 이었다면, `action`으로 이름을 바꾸면서 **Server Action**에 초점을 두고 설계되었다.

`const [state, formAction, isPending] = useActionState(fn, initialState, permalink?)`

- 상태, isPending과 같은 값들을 tanstack query 같은 라이브러리를 사용하지 않고도 한번에 관리할 수 있음
- RSC를 지원하는 프레임워크를 사용할 때 Server Action 으로도 활용이 가능하다.

## Parameters

- `fn`: 실행되는 action 함수, 그 반환값이 다음 state로 저장된다.
- `initialState`: 첫 action이 실행되기 전 state의 최초 값
- `permalink` : JS가 로드되기 전에 action이 실행될 경우, 브라우저가 지정한 URL(fallback URL)로 이동하도록 함

## Return

- `state`: 마지막 action의 결과 (fn이 반환한 값), 최초에는 `initialState`, 새로운 action이 완료되기 전에는 이전 값 유지
- `formAction` : `fn`을 실행하기 위한 핸들러
- `isPending` : action 함수 처리 완료 여부

## Example

```jsx
"use client";

import { useActionState } from "react;
import { login } from "./actions/login";

export default function LoginPage() {
  const [state, formAction, isPending] = useActionState(login, {
    email: "",
    password: "",
  });

  const { email, password } = state;

  return (
    <form action = {formAction}>
      ...
      <button disabled={isPending}>login</button>
    </form>
  );
}
```
