# Week 01

## useActionState

> `useActionState`: form action의 결과값에 따라 state를 update하는 Hook

### Reference

1. 사용을 위해 component의 최상위에 작성해야 한다.
2. 전달값 : form action function, initial state
3. return : new form action, 업데이트 된 form state, action이 pending인지의 여부

#### Parameters

- `fn`: form을 제출하거나 버튼을 눌렀을때 호출된다. 첫번째 인자로 form의 이전 state, 그 다음 인자로 form action이 받는 인자들을 받는다.
- `initialState`: 초기 설정 값. 아무 타입이나 다 설정할 수 있다.
- optional `permalink`: form이 수정하는 고유한 페이지 URL을 포함하는 문자열.
  - dynamic content를 위해 `progressive enhancement`와 같이 사용된다.
  - `fn`이 서버함수이고 JS 번들이 로드 되기 전에 form이 제출 된다면, 브라우저가 permalink URL로 이동한다.

#### Returns

배열형태로 아래 값들을 반환한다.

- The current state
- A new action: `action` prop형태로 전달할 수 있다.
- The isPending flag

#### Caveats

1. React Server Components를 지원하는 프레임워크에서 사용할 경우, `useActionState`가 JavaScript 실행 전에 form을 interactive하게 할 수 있다.
2. `useActionState` hook으로 넘겨진 function은 추가 인자를 받기 때문에 hook을 사용하지않고 호출할때와 다를 수 있다.

### e.g.

```javascript
import { useActionState } from "react";

async function increment(previousState, formData) {
  return previousState + 1;
}

function StatefulForm({}) {
  const [state, formAction] = useActionState(increment, 0);
  return (
    <form>
      {state}
      <button formAction={formAction}>Increment</button>
    </form>
  );
}
```
