# Week 01

## [useActionState(action, initialState, permalink?)](https://react.dev/reference/react/useActionState)

- Form action 결과를 바탕으로 state를 갱신할 수 있게 하는 hook (과거의 `useFormState`)
- Server Function과 함께 사용하면 hydration이 완료되기 이전에 server에서 form을 submit 한 결과(response)를 미리 받아올 수 있음

### API

```javascript
async function increment(previousState, formData) {
  return previousState + 1;
}

const [state, formAction, isPending] = useActionState(increment, 0, null);
```

- **Arguments**
  - `action`
    - Form이 submit 될 때 (`<form>` 내부의 `<button>`을 누를 때) 호출되는 함수
    - Form의 previous state와 form에 입력된 값을 parameter로 받음
  - `initialState` : 초기 state 값
  - `permalink` (optional)
    - Form이 수정되는 page URL로, dynamic content를 가진 page에서 활용
    - `action`이 server function이고 form이 JS bundle이 load되기 이전에 submit 되었다면, browser는 현재 page URL이 아닌 `permalink`로 이동
- **Returns**
  - `state` : the current state
    - 최초 render 시 기본값(`initialState`)
    - 이후, form이 submit 될 때 `action` 함수에서 반환되는 값
  - `formAction`
    - 사용자의 submit action에 의해 실행시키거나,
      - `<form>`의 `action` prop으로 전달
      - `<form>` 내부에 있는 `<button>`의 `formAction` prop으로 전달
    - `startTransition`으로 직접 실행
  - `isPending` : transition이 pending 상태인지 여부
- **Caveats**
  - RSC를 지원하는 framework에서 사용하면 JS가 client에서 실행되기 전에 form을 interactive하게 만들어 줌
  - Server component 없이 사용하면 일반적인 local state와 동일
  - `useFormState`에 전달하는 `action` 함수는 첫 번째 argument로 previous state를 받는다는 점에서 일반적인 form action과 차이가 있음

### Usage

**actions.js**

```javascript
"use server";

export async function addToCart(prevState, queryData) {
  const itemID = queryData.get("itemID");
  if (itemID === "1") {
    return {
      success: true,
      cartSize: 12,
    };
  } else {
    return {
      success: false,
      message: "The item is sold out.",
    };
  }
}
```

**App.jsx**

```javascript
import { useActionState } from "react";
import { addToCart } from "./actions.js";

function AddToCartForm({ itemID, itemTitle }) {
  const [formState, formAction] = useActionState(addToCart, {});

  return (
    <form action={formAction}>
      <h2>{itemTitle}</h2>
      <input type="hidden" name="itemID" value={itemID} />
      <button type="submit">Add to Cart</button>
      {formState?.success && (
        <div className="toast">
          Added to cart! Your cart now has {formState.cartSize} items.
        </div>
      )}
      {formState?.success === false && (
        <div className="error">Failed to add to cart: {formState.message}</div>
      )}
    </form>
  );
}

export default function App() {
  return (
    <>
      <AddToCartForm itemID="1" itemTitle="JavaScript: The Definitive Guide" />
      <AddToCartForm itemID="2" itemTitle="JavaScript: The Good Parts" />
    </>
  );
}
```
