# useActionState

useActionState는 form action의 결과를 기반으로 상태를 업데이트 해주는 Hook

## Reference

`useActionState(action, initialState, permalink?)`

- useActionState를 컴포넌트 최상위 레벨에서 호출시, form action 이 호출될 때 업데이트 되는 컴포넌트 상태를 만들 수 있음
- useActionState에는 기존 form action 함수와 초기 state를 전달
- form state는 폼이 마지막으로 제출됐을때 action이 반환한 값
- 서버 함수와 사용하면 hydration이 완료되기 전에 form을 제출한 결과를 보여줄수 있음
- return : form에서 사용할 새로운 action, 최신 form state , 처리중인지 여부

```javascript
async function increment(previousState, formData) {
  return previousState + 1;
}

function StatefulForm({}) {
  const [state, formAction] = useActionState(increment, 0);
  return (
    <form>
      {state}
      <button formAction={formAction}>Increment</button>
    </form>
  );
}
```

## Parameters

- fn
  - 폼이 제출되거나 버튼을 눌렀을때 호출하는 함수
  - 함수가 호출되면 첫번째 인자로는 form의 이전 state, 다음 인자들은 form action 값들을 받음
- initialState
  - state의 초기값
- optional permalink
  - form이 수정하는 고유한 URL
  - 동적 컨텐츠가 있는 페이지에서 사용
  - fn이 서버함수고 javasScript 번들이 로드되기 전에 폼이 제출되면, 브라우저가 지정된 permalink URL로 이동
  - React가 state를 전달할 수 있도록 목적지 페이지에서 동일한 form 컴포넌트가 렌더링 되어야함

## Returns

- current state
  - 첫 렌더링시 initialSate
  - action 호출 이후에는 action이 반환한 값
- form 의 action prop이나 button의 formAction prop 으로 전달할 수 있는 새 action
- isPending 플래그

## Caveats

- React Server Components를 지원하는 프레임워크에서 사용하면 클라이언트에서 자바스크립트가 실행되기 전에도 form을 interactive하게 만들 수 있음
- Server Component 없이 사용하면 컴포넌트 local state랑 같음
- useActionState에 전달한 함수는 첫 번째 인자로 이전/초기 state를 추가로 받음
- useActionState 없이 form action으로 직접 사용할때와 함수 시그니쳐가 다름

## Usage

```javascript
import { useActionState } from 'react';
import { action } from './actions.js';

function MyComponent() {
  const [state, formAction] = useActionState(action, null);
  // ...
  return <form action={formAction}>{/* ... */}</form>;
}
```

- useActionState가 반환하는 항목들
  - current state : 초기에는 initial state, 이후에는 action의 반환값
  - new action: form의 action prop으로 전달하거나 startTranslation 안에서 호출할 action
  - pending state
- form이 제출되면 전달한 함수가 호출되고 반환값이 current state가 됨
- 전달한 action은 추가적인 첫번째 인자로 current state를 받음

## Troubleshooting

- useActionState를 사용하면 form action이 추가적인 인자를 받아 인자 순서가 `(currentState, formData)`로 변경됨
