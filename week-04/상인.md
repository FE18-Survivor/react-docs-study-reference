# useEffectEvent

## Reference

`useEffectEvent(callback)`

Effect 내부 로직을 밖으로 추출해, Event와 비슷한 Effect Event라는 함수를 만들 수 있게 해주는 Hook이다.

- `callback`: Effect Event 함수
- Effect 내부에서만 호출하기
- 다른 컴포넌트로 전달하지 않기

## Usage

```jsx
import { useEffect, useContext, useEffectEvent } from "react";

function Page({ url }) {
  const { items } = useContext(ShoppingCartContext);
  const numberOfItems = items.length;

  const onNavigate = useEffectEvent((visitedUrl) => {
    logVisit(visitedUrl, numberOfItems);
  });

  useEffect(() => {
    onNavigate(url);
  }, [url]);

  // ...
}
```

# useId

## Reference

`useId()`

접근성 속성 등에 전달할 수 있는 고유한 ID를 생성하기 위한 Hook

- list의 key를 위해 사용하지 않기
- Server Component에서 사용할 필요 없음

## Usage

```jsx
// ID 생성하기
import { useId } from "react";

function PasswordField() {
  const passwordHintId = useId();
  return (
    <>
      <label>
        Password:
        <input type="password" aria-describedby={passwordHintId} />
      </label>
      <p id={passwordHintId}>
        The password should contain at least 18 characters
      </p>
    </>
  );
}
```

```jsx
// 공유 접두사로 활용하기
export default function Form() {
  const id = useId();
  return (
    <form>
      <label htmlFor={id + "-firstName"}>First Name:</label>
      <input id={id + "-firstName"} type="text" />
      <hr />
      <label htmlFor={id + "-lastName"}>Last Name:</label>
      <input id={id + "-lastName"} type="text" />
    </form>
  );
}
```

# useLayoutEffect

## Reference

`useLayoutEffect(setup, dependencies?)`

- `useEffect`: 브라우저의 paint 이후 시점에 계산
- `useLayoutEffect`: paint 이전에 계산

### Parameters & Return

- `setup`: Effect 로직 함수. cleanup을 포함할 수 있음
- optional `dependencies`: setup 함수 내에서 참조된 모든 reactive values 리스트
- `반환값`: `undefined`

### Caveats

- useLayoutEffect를 과도하게 사용하면 앱이 느려짐 (paint 전에 동기적으로 실행되기 때문에 끝날 때까지 paint 못해서)
  - useLayoutEffect 실행 -> setState -> re-render -> useLayoutEffect 실행 (의존성까지 있다면 무한 루프) -> Paint

```jsx
useLayoutEffect(() => {
  setState((prev) => prev + 1);
});
```

- useLayoutEffect 내부에서 state 업데이트 시 렌더가 끝난 뒤 Effect를 모두 실행함
  - render -> commit -> useLayoutEffect (setState) -> render -> commit -> useLayoutEffect -> paint -> useEffect

```jsx
useLayoutEffect(() => {
  setCount((prev) => prev + 1);
}, []);

useEffect(() => {
  console.log("testtttt");
}, []);
```

> 결론적으로 useLayoutEffect는 두 번의 렌더링을 거치므로 느려질 수 있으니 남발하지 않기

## Usage

- 브라우저가 화면에 그리기 전에 레이아웃을 계산하고 싶을 때 사용하기
  - render -> commit -> useLayoutEffect (크기 측정 후 setState) -> render -> commit -> useLayoutEffect -> paint

```jsx
function Tooltip() {
  const ref = useRef(null);
  const [tooltipHeight, setTooltipHeight] = useState(0);

  useLayoutEffect(() => {
    const { height } = ref.current.getBoundingClientRect();
    setTooltipHeight(height);
  }, []);
}
```
