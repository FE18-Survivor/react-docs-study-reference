# useCallback

> `useCallback`은 렌더링 사이에 함수정의를 cache 해주는 hook이다.

```javascript
const cachedFn = useCallback(fn, dependencies);
```

## Reference

```javascript
import { useCallback } from 'react';

export default function ProductPage({ productId, referrer, theme }) {
  const handleSubmit = useCallback((orderDetails) => {
    post('/product/' + productId + '/buy', {
      referrer,
      orderDetails,
    });
  }, [productId, referrer]);
  ...
```

### Parameters

- `fn`: 캐싱하고 싶은 함수. 무엇이든 인자로 받을 수 있고 return 할 수 있다. dependencies가 바뀌지 않았다면 렌더링 할때마다 동일한 함수를 받을 수 있다.

- `dependencies`: `fn` code가 참조하는 모든 reactive values. `props`, `states`, `variables`, `functions`

### Returns

1. 초기 렌더링일때 : useCallback 함수에 처음 넘긴 `fn`
2. dependency가 바뀌지 않았을 때 : 저장된 `fn`
3. dependency가 바뀌었을 때 : 해당 렌더링때 넘긴 `fn`

### Caveats

- Hook이기 때문에 컴포넌트의 top level에만 작성할 수 있다.
- useCallback에 cached된 함수는 특별한 이유가 없다면 계속 저장되어 있다.

## Usage

### Skipping re-rendering of components

- 자식 컴포넌트에 넘겨줄 function을 caching 해서 부모 컴포넌트에서 re-render가 되어도 자식 컴포넌트는 렌더링을 skip할 수 있다.

- **성능 최적화**를 위해서만 사용해야 하며, `useCallback`없이 동작하지 않는다면 해당 코드부터 먼저 수정해야한다.

**useMemo, useCallback**

- useMemo : 함수의 결과값을 caching. 함수를 호출한다.
- useCallback : 함수 자체를 caching. 함수를 호출하지 않는다.

**useCallback을 사용하면 좋은 경우**

- dependency에 따라서 rendering을 skip하고 싶을 때.
- 어떠한 Hook에 dependency로 나중에 사용하고 싶을 때.

### Updating state from a memoized callback

```javascript
function TodoList() {
  const [todos, setTodos] = useState([]);

  const handleAddTodo = useCallback((text) => {
    const newTodo = { id: nextId++, text };
    setTodos(todos => [...todos, newTodo]);
  }, []); // ✅
  // ...
```

- updater function을 전달함으로써, dependency를 제거할 수 있다.

## Troubleshooting

- `useCallback`을 사용할 때, 적절한 dependency를 작성했는지 확인한다. [관련 링크](https://react.dev/reference/react/useCallback#every-time-my-component-renders-usecallback-returns-a-different-function)
- `useCallback`은 loop문 같은 곳에서 사용이 불가능 하므로, 사용을 원하는 함수가 있다면 컴포넌트를 분리하여 사용한다. [관련 링크](https://react.dev/reference/react/useCallback#i-need-to-call-usememo-for-each-list-item-in-a-loop-but-its-not-allowed)
