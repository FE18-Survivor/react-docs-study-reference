# useMemo

## Reference

`useMemo(calculateValue, dependencies)`

렌더링 중 비싼 계산 결과를 메모이제이션(캐싱) 하기 위한 Hook이다.

의존성이 변경되지 않는 한, 이전에 계산한 값을 재사용한다.

### Parameters & Return

`calculateValue`: 메모이제이션할 값을 계산하는 함수. 순수 함수여야 함

`dependencies`: `calculateValue` 내부에서 사용하는 모든 reactive values 배열

`반환값`: calculateValue가 반환한 값

### Caveats

- 성능 최적화 용도이며 정확성을 위해 사용하면 안 됨
- 의존성이 바뀌면 다시 계산됨
- Strict Mode에서는 개발 환경에서 두 번 호출될 수 있음

## Usage

렌더링 시마다 실행하면 비용이 큰 계산을 useMemo로 감싸서, 의존성이 바뀔 때만 다시 계산하도록 만든다.

- todos 또는 tab이 바뀔 때만 filterTodos 실행
- 그 외 렌더에서는 이전 계산 결과 재사용

```jsx
import { useMemo } from "react";

function TodoList({ todos, tab }) {
  const visibleTodos = useMemo(() => {
    return filterTodos(todos, tab);
  }, [todos, tab]);

  return (
    <ul>
      {visibleTodos.map((todo) => (
        <li key={todo.id}>{todo.text}</li>
      ))}
    </ul>
  );
}

function filterTodos(todos, tab) {
  console.log("Filtering todos...");
  return todos.filter((todo) => {
    if (tab === "all") return true;
    if (tab === "active") return !todo.completed;
    if (tab === "completed") return todo.completed;
  });
}
```

memo로 감싼 컴포넌트는 props가 같으면 재렌더링을 건너뜀. 이때 useMemo로 객체 참조를 고정해야 효과가 있음

```jsx
import { useMemo } from "react";

function ChatRoom({ roomId }) {
  const options = useMemo(() => {
    return {
      serverUrl: "https://localhost:1234",
      roomId: roomId,
    };
  }, [roomId]);

  return <Chat options={options} />;
}

import { memo } from "react";

const Chat = memo(function Chat({ options }) {
  // ...
});
```

Effect의 의존성에 객체나 배열이 들어갈 경우, 렌더마다 새로 만들어지면 Effect도 계속 다시 실행됨.

- options가 바뀔 때만 Effect 실행
- 불필요한 재연결 방지

```jsx
import { useEffect, useMemo } from "react";

function ChatRoom({ roomId }) {
  const options = useMemo(() => {
    return {
      serverUrl: "https://localhost:1234",
      roomId: roomId,
    };
  }, [roomId]);

  useEffect(() => {
    const connection = createConnection(options);
    connection.connect();
    return () => connection.disconnect();
  }, [options]);
}
```

useEffect, useCallback 같은 Hook의 dependency로 쓰이는 값이
매 렌더마다 새로 만들어지면 Hook도 계속 재실행됨

- text가 바뀔 때만 searchOptions 변경
- Effect 불필요한 재실행 방지

```jsx
const searchOptions = useMemo(() => {
  return { matchMode: "whole-word", text };
}, [text]);

useEffect(() => {
  doSearch(searchOptions);
}, [searchOptions]);
```

함수도 결국 값이므로 useMemo로 메모화할 수 있다.

- productId, referrer가 바뀔 때만 새 함수 생성
- 자식 컴포넌트에 함수 전달 시 재렌더 방지 가능

```jsx
const handleSubmit = useMemo(() => {
  return (orderDetails) => {
    post("/product/" + productId + "/buy", {
      referrer,
      orderDetails,
    });
  };
}, [productId, referrer]);
```
