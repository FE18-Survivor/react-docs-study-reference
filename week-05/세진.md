# useMemo

> useMemo는 re-render 사이에 계산된 결과를 caching 하는 hook 이다.

## Reference

```javascript
import { useMemo } from "react";

function TodoList({ todos, tab }) {
  const visibleTodos = useMemo(() => filterTodos(todos, tab), [todos, tab]);
  // ...
}
```

### Parameters

- `calculateValue` : caching 하고 싶은 결과값을 계산하는 함수. 순수함수여야 하고, arguments를 받으면 안되고, 어느 타입이든 return 할 수 있다. dependencies가 변하지 않으면 첫 렌더 이후 같은 값을 return한다.
- `dependencies` : `calculateValue` 코드 속에 있는 reactive value의 list.

### Returns

- initial Render : `calculateValue` 호출한 결과 값.
- next render : dependencies가 변경되지 않았다면 initial render때와 동일한 값, 변경되었다면 해당 값을 기준으로 한번 더 `calculateValue`를 호출하고 그 결과값을 반환 한다.

### Caveats

`useMemo`로 caching 된 값은 버려질 수도 있다. 개발모드에서 파일을 수정하면 cache가 버려지고, 컴포넌트의 초기 마운트 중에 suspend가 되어도 동일하다. 따라서 버려지면 안될 값은 `useMemo`가 아닌, `useState`, `useRef`등을 사용하는것이 더 적절할 수 있다.

## Usage

1. [Skipping expensive recalculations](https://react.dev/reference/react/useMemo#skipping-expensive-recalculations)
2. [Skipping re-rendering of components](https://react.dev/reference/react/useMemo#skipping-re-rendering-of-components)

비용높은 계산이나 컴포넌트의 re-render를 skip하기 위해 `useMemo`를 사용할 수 있다.

그렇지만 모든곳에 해당 hook을 사용할 필요는 없다. 그렇게 많지 않은 상황에서만 유용하기 때문이다.

- useMemo 안에 넣은 계산이 눈에 띄게 느리고, dependencies가 거의 변경되지 않는 경우

- memo로 감싼 컴포넌트에 prop으로 전달하는 경우
  값이 변경되지 않았다면 리렌더링을 건너뛰고 싶을 때.
  메모이제이션을 사용하면 의존성이 동일하지 않을 때만 컴포넌트가 다시 렌더링된다.

- 전달한 값이 이후에 어떤 Hook의 의존성으로 사용되는 경우.
  예를 들어, 다른 useMemo 계산 값이 이 값에 의존할 수도 있고,
  또는 useEffect에서 이 값에 의존하고 있을 수도 있다.

페이지 전체나 섹션 하나를 교체하는 식이면 hook 사용을 추천하지 않고, 상호작용이 세밀한 컴포넌트일 경우 추천한다.

## [Troubleshooting](https://react.dev/reference/react/useMemo#troubleshooting)

- `dependencies`가 직접 변경되면 안된다.
- `dependencies`가 생략되면 안된다.
- hook을 loop안에서 호출하면 안된다.
