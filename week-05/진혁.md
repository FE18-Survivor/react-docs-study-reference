# useMemo
useMemo는 리렌더링 사이에서 계산 결과를 캐시해주는 React Hook

```javascript
const cachedValue = useMemo(calculateValue, dependencies);
```

## Note
> React Compiler를 사용하면 값과 함수가 자동으로 메모이제이션되어서 수동으로 useMemo를 사용 할 일이 줄어든다

## Reference
```javascript
function TodoList({ todos, tab }) {
  const visibleTodos = useMemo(
    () => filterTodos(todos, tab),
    [todos, tab]
  );
}
```
컴포넌트 최상위에서 호출하여 리렌더링 사이에 계산 결과를 캐시

## Parameters
```calculateValue```
- 캐시하고 싶은 값을 계산 하는 함수
- 순수한(pure) 함수, 인자를 받지 않아야 함, 어떤 타입의 값이든 반환 가능
- 초기 렌더링 시 실행
- 이후 렌더링에서 의존성이 변하지 않으면 이전 값을 그대로 반환

```dependencies```
- 계산 함수(calcuateValue) 내부에서 사용되는 모든 반응형 값의 배열
  - 모든 props, state, 변수, 함수 포함
- 고정된 길이의 배열을 인라인 형태로 작성
- ```object.is``` 로 이전 값과 비교

## Returns
- 초기 렌더링 시: calculateValue() 의 반환 값
- 이후 렌더링 :
  - 의존성 변경 X -> 이전 캐시 값
  - 의존성 변경 O -> 재계산한 값
 
## Caveats
- Hook이므로 루프나 조건문 안에서 호출 불가
- Strict Mode 에서는 계산 함수가 두번 호출됨 (순수성 검사)
- React는 필요시 캐시를 버릴 수 있음
  - ex) 개발중 파일 수정, 마운트중 suspense 발생
  - React에서 향후에 캐시를 버리는 동작을 활용하는 더 많은 기능을 추가할 수도 있음
- useMemo는 성능 최적화용

## Usage
### 비용이 많이드는 계산 스킵하기
```javascript
const visibleTodos = useMemo(
  () => filterTodos(todos, tab),
  [todos, tab]
);
```
- todos, tab 이 바뀌지 않으면 이전 계산 결과 재사용
- 큰 배열 필터링, 복잡한 계산에 유용
- _**useMemo는 성능 최적화를 위해서만 사용, useMemo없이 로직이 깨진다면 설계 문제**_

### 컴포넌트 리렌더링 스킵하기
**문제 상황:**
```javascript
export default function TodoList({ todos, tab, theme }) {
  const visibleTodos = filterTodos(todos, tab);
  return (
    <div className={theme}>
      <List items={visibleTodos} />
    </div>
  );
}
```
- theme 변경시 TodoList 리렌더링
- filterTodos는 새로운 배열 생성
- visibleTodos 참조값 변경
- List 리렌더링

**해결:** 
```javascript
export default function TodoList({ todos, tab, theme }) {
  const visibleTodos = useMemo(
    () => filterTodos(todos, tab),
    [todos, tab] 
  );
  return (
    <div className={theme}>
      <List items={visibleTodos} />
    </div>
  );
}
```
- visibleTodos에 useMemo 사용
- visibleTodos의 참조값 유지
- List 리렌더링 스킵

### Effect가 너무 자주 실행되는 것 방지하기
**문제 상황:**
```javascript
function ChatRoom({ roomId }) {
  const [message, setMessage] = useState('');

  const options = {
    serverUrl: 'https://localhost:1234',
    roomId: roomId
  }
useEffect(() => {
  const connection = createConnection(options);
  connection.connect();
  return () => connection.disconnect();
}, [options]);
```
- Effect안에서 사용되는 모든 반응형 값은 dependecy로 선언해야함
- options를 depedency로 선언 -> ChatRoom 리렌더링시 Effect 재실행

**해결 방법 1:**
```javascript
function ChatRoom({ roomId }) {
  const [message, setMessage] = useState('');

  const options = useMemo(() => {
    return {
      serverUrl: 'https://localhost:1234',
      roomId: roomId
    };
  }, [roomId]); 

  useEffect(() => {
    const connection = createConnection(options);
    connection.connect();
    return () => connection.disconnect();
  }, [options]); 
}
```
- options 객체는 동일한 참조 유지
- _주의:_ useMemo는 성능 최적화용 도구 -> 캐시값을 버릴 수 있음

**해결 방법 2 (권장):**
```javascript
function ChatRoom({ roomId }) {
  const [message, setMessage] = useState('');

  useEffect(() => {
    const options = { 
      serverUrl: 'https://localhost:1234',
      roomId: roomId
    };

    const connection = createConnection(options);
    connection.connect();
    return () => connection.disconnect();
  }, [roomId]); // 
}
```
- 객체를 Effect 내부로 이동
- 코드 단순화, useMemo 사용 X

### 다른 훅의 dependency 메모이제이션하기

**문제 상황:**
```javascript
function Dropdown({ allItems, text }) {
  const searchOptions = { matchMode: 'whole-word', text };

  const visibleItems = useMemo(() => {
    return searchItems(allItems, searchOptions);
  }, [allItems, searchOptions]); 
}
```
- Dropdown 리렌더링시 searchOptions 객체 새로 생성
- searchItems 재실행
- useMemo 의미없어짐

**해결 방법1:**
```javascript
function Dropdown({ allItems, text }) {
  const searchOptions = useMemo(() => {
    return { matchMode: 'whole-word', text };
  }, [text]); 

  const visibleItems = useMemo(() => {
    return searchItems(allItems, searchOptions);
  }, [allItems, searchOptions]);
}
```
- searchOptions 객체 useMemo로 감싸기

**해결 방법2(권장):**
```javascript
function Dropdown({ allItems, text }) {
  const visibleItems = useMemo(() => {
    const searchOptions = { matchMode: 'whole-word', text };
    return searchItems(allItems, searchOptions);
  }, [allItems, text]);
}
```
- 객체 생성을 useMemo 내부로 이동
- searchOptions 객체가 아닌 string인 text에 직접 의존

### 함수 메모이제이션하기
**문제 상황:**
Form 컴포넌트가 memo로 감싸져있다고 가정
```javascript
export default function ProductPage({ productId, referrer }) {
  function handleSubmit(orderDetails) {
    post('/product/' + productId + '/buy', {
      referrer,
      orderDetails
    });
  }

  return <Form onSubmit={handleSubmit} />;
}
```
- 리렌더링시 새로운 hadlesubmit 함수 생성 -> Form 컴포넌트 리렌더링

**해결 방법:**
```javascript
export default function Page({ productId, referrer }) {
  const handleSubmit = useCallback((orderDetails) => {
    post('/product/' + productId + '/buy', {
      referrer,
      orderDetails
    });
  }, [productId, referrer]);

  return <Form onSubmit={handleSubmit} />;
}
```
- useMemo 대신 useCallback 사용
- 둘은 동일하게 작동
- useCallback은 중첩 함수 작성을 피할 수 있음

## Troubleshooting
### 리렌더링시 계산이 두번 실행됨
- Strict Mode에서는 기본적으로 두 번 호출
- 개발 환경 전용 동작
- 순수성 검사 목적

### useMemo가 객체 대신 undefined를 반환할 때
**잘못된 예**
```javascript
const searchOptions = useMemo(() => {
  matchMode: 'whole-word',
  text: text
}, [text]);
```

**해결 방법**
```javascript
const searchOptions = useMemo(() => {
  return {
    matchMode: 'whole-word',
    text: text
  };
}, [text]);
```

### useMemo 계산이 매번 실행됨
- dependency 배열 확인

### useMemo를 loop의 item안에서 사용하고 싶을때
**문제 상황:**
```javascript
<article>
      {items.map(item => {
        // 🔴 useMemo 사용 불가
        const data = useMemo(() => calculateReport(item), [item]);
        return (
          <figure key={item.id}>
            <Chart data={data} />
          </figure>
        );
      })}
    </article>
```

**해결 방법1:**
```javascript
    <article>
      {items.map(item =>
        <Report key={item.id} item={item} />
      )}
    </article>
...
  function Report({ item }) {
    const data = useMemo(() => calculateReport(item), [item]);
    return (
      <figure>
        <Chart data={data} />
      </figure>
    );
  }
```
- 컴포넌트 분리후 useMemo 사용

**해결 방법2:**
```javascript
const Report = memo(function Report({ item }) {
  const data = calculateReport(item);
  return (
    <figure>
      <Chart data={data} />
    </figure>
  );
});
```
- 컴포넌트 자체를 memo로 감싸기
