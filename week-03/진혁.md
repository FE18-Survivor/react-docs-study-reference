# useDebugValue
useDebugValue는 React DevTools에서 커스텀 Hook에 라벨을 추가할 수 있게 해주는 React Hook
```useDebugValue(value, format?)```

## Reference
커스텀 Hook의 최상위 에서 useDebugValue를 호출하면, 디버그값을 나타낼 수 있다.
```javascript
function useOnlineStatus() {
  useDebugValue(isOnline ? 'Online' : 'Offline');
}
```

## Parameters
- ```value``` : React DevTools에서 표시할 값. 모든 타입 가능
- optional ```format?``` : - 포멧팅 함수, value를 인자로 받아 포멧된 값 반환

## Returns
- useDebugValue 는 값을 반환하지 않음

## Usage
### 커스텀 Hook에 라벨 추가하기
```javascript
function useOnlineStatus() {
  useDebugValue(isOnline ? 'Online' : 'Offline');
}
```
- 커스텀 훅 최상위에서 useDebugValue 호출
- useOnlineStatus를 사용하는 컴포넌트 검사시 ```OnlineStatus: "Online"``` 확인 가능
<br>
[예시](https://react.dev/reference/react/useDebugValue#adding-a-label-to-a-custom-hook)

### 디버그값 포멧팅
```javascript
useDebugValue(date, date => date.toDateString());
```
- 포멧팅 함수는 디버그값을 인자로 받아 나타낼 값을 번환
- 컴포넌트를 검사할 때 반환값이 React DevTools에 나타난다

# useDeferredValue
useDeferredValue는 UI의 일부 업데이트를 지연시켜주는 React Hook
```javascript
const deferredValue = useDeferredValue(value)
```

## Reference
```useDeferredValue(value, initialValue?)```
```javascript
function SearchPage() {
  const [query, setQuery] = useState('');
  const deferredQuery = useDeferredValue(query);
  // ...
}
```
컴포넌트 최상위에서 useDeferredValue를 호출하여 해당 값의 지연된 버전을 얻을 수 있음

## Parameters
- ```value``` : 지연시키고 싶은 값. 모든 타입 가능
- optional ```initialValue?``` : 컴포넌트 초기 렌더링시 이전값이 없으므로 사용할 값

## Returns
- 초기 렌더링시 : ```initialValue``` 가 있으면 그 값, 없을 시 전달한 ```value```
- 업데이트시 : 이전 값을 사용해 리렌더링, 이후 백그라운드에서 새 값을 사용하여 리렌더링

## Caveats
- 업데이트가 Transition 안에서 발생한 경우
  - 이미 업데이트가 지연되고 있기 때문에 useDeferredValue는 항상 새 값을 반환
- useDeferredValue 에 전달하는 값은 원시값 이거나 렌더링 외부에서 생성된 객체여야함
  - 렌더링중 새 객체를 전달하면 매 렌더마다 다른 값으로 인식되어 불필요한 백그라운드 렌더링 발생
- useDeferredValue 가 다른 값을 받을때
  - 현재 렌더링과 별도로 새 값을 사용한 리렌더링을 백그라운드에 예약
  - 값이 도중에 업데이트되면 백그라운드 리렌더링을 다시 시작
- useDefferredValue는 ```<Suspense>``` 랑 통합되어 있음
  - 백그라운드 업데이트가 새로운 값에 의해 지연될때, fallback 을 보여주지 않고 이전 값을 보여줌
- useDeferredValue 자체는 네트워크 요청을 줄이지 않음
- 고정된 지연시간은 없음
- 백그라운드 렌더링이 커밋되기 이전에는 Effect를 실행하지 않음

## Usage
### 최신 컨텐츠가 로딩되는 동안 이전 콘텐츠를 표시
```javascript
  const [query, setQuery] = useState('');
  const deferredQuery = useDeferredValue(query);
  return (
    <>
      <label>
        Search albums:
        <input value={query} onChange={e => setQuery(e.target.value)} />
      </label>
      <Suspense fallback={<h2>Loading...</h2>}>
        <SearchResults query={deferredQuery} />
      </Suspense>
    </>
  );
```
- 입력값은 즉시 업데이트
- 결과는 fallback을 보여주지 않고 이전 결과를 유지하다 새 결과로 업데이트


### 오래된 컨텐츠임을 나타내기
```javascript
const isStale = query !== deferredQuery;

<div style={{ opacity: isStale ? 0.5 : 1 }}>
  <SearchResults query={deferredQuery} />
</div>
```
- deferred 값으로 이전 결과를 흐리게 만들어 사용자에게 나타낼 수 있음

### UI 일부분 리렌더링 지연하기 (최적화)
```javascript
const SlowList = memo(function SlowList({ text }) {
  // ...
});
```
```javascript
const [text, setText] = useState('');
  const deferredText = useDeferredValue(text);
  return (
    <>
      <input value={text} onChange={e => setText(e.target.value)} />
      <SlowList text={deferredText} />
    </>
  );
```
- useDeferredValue를 사용하여 이전 값(props) 유지
- memo 로 리렌더링 방지
